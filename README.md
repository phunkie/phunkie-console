phunkie-console
===============

🚨 ⚠️ This project has been discontinued in favour of [phunkie/console](https://github.com/phunkie/console) development.

phunkie-console is a a REPL to support your [Phunkie](https://github.com/phunkie/phunkie) development

```bash
$ bin/phunkie-console
Welcome to phunkie console.

Type in expressions to have them evaluated.

phunkie >
```
